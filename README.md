# Image Adjuster

**Image Adjuster** is a powerful web-based tool for editing and enhancing images using the capabilities of OpenCV. Adjust brightness, contrast, saturation, apply filters, and more—all in real-time through your browser!

🔗 **Live Demo**: [https://yogeswara97.github.io/Image-Adjuster/](https://yogeswara97.github.io/Image-Adjuster/)
